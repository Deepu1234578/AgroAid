# AgroAid
This is AgroAid — an Android app (Java, Gradle) for farmers: it does plant disease detection (camera + Plant.id-style API + Claude AI for diagnosis/treatment), local weather via Open-Meteo, commodity market price tracking with charts, and Google/Supabase-based login &amp; profile setup.

# AgroAid 🌱

An Android app that helps farmers make better decisions through AI and real-time data.

## Features
- 📷 **Plant Disease Detection** — Scan a plant photo to identify diseases, get 
  treatment suggestions, and prevention tips using AI (Claude) and a plant health API
- 🌦️ **Weather Forecasts** — Local weather via Open-Meteo based on device location
- 📈 **Market Prices** — Track commodity prices with interactive charts
- 🔐 **Authentication** — Email/Google sign-in with Supabase backend
- 👤 **Profile Setup** — Personalized farmer profiles

## Tech Stack
- Java, Android SDK, Gradle (Kotlin DSL)
- OkHttp for networking
- Supabase (auth/backend)
- Claude API (AI plant diagnosis)
- Open-Meteo API (weather)
- MPAndroidChart (market price charts)
